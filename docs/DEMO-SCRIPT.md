# AcePath AI — 2:40 demo script

## 0:00–0:20 — The problem

“Private SAT tutoring can cost hundreds or thousands of dollars. Students with the least access often receive the least personalized preparation. AcePath is a free learning agent designed to change that.”

Show the landing page on a phone-width viewport. Open Accessibility and point out Low Data Mode.

## 0:20–0:55 — Diagnose

Select **Start a diagnostic**. Explain that the diagnostic measures skills independently. Answer the questions and deliberately miss the Quadratics item.

“AcePath does not reduce this to one opaque score. It identifies Quadratics as the first focus, updates the learner model, and generates a five-day plan.”

Show the diagnostic results and select **Start adaptive practice**.

## 0:55–1:50 — The agent acts

On a medium Quadratics question, deliberately choose the wrong factorization.

“This is the difference between a chatbot and an agent. AcePath classified the factoring mistake, changed mastery, rebuilt the plan, scheduled review, and chose a foundation-level factor-pairs question.”

Open the agent note, then choose **Try prerequisite question**. Answer it correctly.

“The prerequisite was successful, so the agent now returns us to the original target.”

Select **Retry the target skill** and answer correctly.

## 1:50–2:20 — Transparent evidence

Open **Agent log**.

“Important decisions are deterministic and auditable. Judges can see the mastery before and after, previous and next difficulty, trigger, and action. The language model may improve an explanation, but it never controls the student’s score or path.”

Open Dashboard, then Mistake Memory.

“Every screen reads the same learner state. The dashboard changed, the mistake was remembered, and its next review was scheduled.”

## 2:20–2:40 — Impact

“AcePath works without a paid AI key, contains no copied official SAT questions, and is designed for low-cost phones, keyboards, screen readers, slow connections, and short study windows. It is not a chatbot waiting for a question. It notices, remembers, acts, and proves why.”

End on the AcePath AI landing page and live demo URL.
